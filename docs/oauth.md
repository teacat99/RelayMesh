# OAuth 2.1 授权服务器（ExecMesh）

RelayMesh Hub 内置 OAuth 2.1 授权服务器与受保护资源元数据，供 ChatGPT、Claude、Claude Code 等 MCP 客户端通过授权码 + PKCE 连接 `/mcp`，无需手动粘贴长期令牌。

## 快速开始

在 Web 的 **设置 → OAuth 授权** 页（旧版本里它嵌在「MCP 与安全」页，现在单独成页），从上到下依次是：状态卡 → 接入窗口 → 接入向导 → 刚登记、还没授权的客户端 → 已授权的应用 → 授权服务器设置。照着下面做即可，不用先读完本文。

OAuth 与下方的「MCP 凭据管理」是两回事：MCP 令牌是你手动复制粘贴的长期凭据；OAuth 是 ChatGPT、Claude 这类连接器在你确认后自动拿到的授权——不用复制任何密钥，随时可以撤销。**默认关闭。**

1. **看状态卡。**「总开关」一行写着它现在到底有没有在服务（被环境变量 `RELAYMESH_OAUTH=off` 关掉时会明确写出来）；「对外地址」一行写着地址从哪来。出现黄色警告「没有设置，按你现在访问页面的地址推导」，说明 ChatGPT / Claude 在公网上访问不到——先在「授权服务器设置」里填好对外地址（`https://你的域名`），或设置环境变量 `RELAYMESH_PUBLIC_URL`。
2. **打开总开关并保存。** 勾选「启用 OAuth 授权服务器」，点「保存策略」（需要再次验证 Web 密码）。
3. **选你的客户端。** 接入向导有三个标签：ChatGPT、Claude（网页）、Claude Code。点「按此客户端设置」会替你勾好这个客户端需要的选项（目前就是「自动注册」，选成默认的「限时窗口」，三个客户端都靠它连接）——它**只勾选**，不会替你打开总开关、也不会替你保存，仍要你自己点「保存策略」。
4. **复制连接器地址。** 状态卡里的「连接器地址」就是 `<对外地址>/mcp`，点「复制」即可。
5. **点「一键自检」。** 它在你的浏览器里检查三件事：两个元数据端点返回 200 且字段齐全；不带令牌的 `POST /mcp` 返回 `401` 并带 `WWW-Authenticate`（就是下文检查清单的第 5 步）。全是绿色再去客户端里添加；有红色时，每一项下面都写了原因和处理办法。注意这是从你现在打开页面的地址发出的检查，只能证明这条访问路径是通的，不代表公网可达。
6. **开启接入窗口。** 自动注册默认是限时窗口：平时关着，客户端自己登记会被拒绝（`403`）。要添加新的连接器，先在页面上方的「接入窗口」卡片里点「开启 10 分钟」（需要再次验证 Web 密码）；添加完点「立即关闭」，或等它到点自己关闭。时间不够就点「续期」，每次在剩余时间上累加 10 分钟，总共最长 60 分钟。如果你把「自动注册」设成了「常开」，可以跳过这一步（不建议长期常开，见下文「自动注册与接入窗口」）。
7. **在客户端里添加并授权。**
   - **ChatGPT**：设置里的「连接器」→ 添加自定义连接器（MCP 服务器），粘贴连接器地址，认证方式选 OAuth。不用填 Client ID / Secret，ChatGPT 会自动向 RelayMesh 注册。
   - **Claude（网页）**：claude.ai 设置里的「连接器」→ 添加自定义连接器，粘贴连接器地址并连接。
   - **Claude Code**：在运行它的那台电脑的终端里执行 `claude mcp add --transport http relaymesh <连接器地址>`，再在 Claude Code 里输入 `/mcp`，选中 relaymesh 并认证。授权要在**同一台电脑**的浏览器里完成：Claude Code 在本机开一个回环端口（127.0.0.1）接收授权结果。

   客户端会把浏览器带到 RelayMesh 的授权页：登录后选择它能在哪些主机上执行命令、最高的执行模式，点「批准」（授予终端能力前要再输入一次密码）。菜单名称以客户端当前的界面为准，找不到时搜「连接器」或「MCP」。
8. **回到设置页确认，并关上接入窗口。** 批准之前，它在「刚登记、还没授权」的清单里（写着登记时间、来源 IP、回调主机，以及「官方来源 / 陌生来源 / 本机回环」标记；不认识的点「删除登记」）；批准之后，它出现在「已授权的应用」里，写着授权时间、最近使用的时间与来源 IP；不想再让它使用，点「撤销」，令牌立即失效。接入窗口用完就点「立即关闭」。

### 它是怎么工作的（人话版）

你只需要在第 6 步开窗口、在第 7 步里点一次「批准」，其余都是客户端和 Hub 自己完成的：

1. **客户端先敲门。** 你在 ChatGPT / Claude 里填了连接器地址（`<对外地址>/mcp`），它第一次访问时没带令牌，Hub 回一个 `401`，并在响应里告诉它「去哪儿查我的授权规则」（发现端点，见下文）。
2. **客户端自己登记。** 它向 `/oauth/register` 报上自己的名字和回调地址，拿到一个 Client ID（这就是「自动注册」的意思，你不用手填任何 ID 或密钥）。只有接入窗口开着时 Hub 才受理这一步，窗口关着它会收到 `403`。
3. **浏览器带你到授权页。** 客户端把浏览器送到 RelayMesh 的授权页 `/oauth/consent`。**这一步才轮到你**：登录 Web、核对页面上写的应用名和回调主机、选它能在哪些主机上执行命令以及最高的执行模式，再点「批准」（授予终端能力前要再输一次密码）。你点「拒绝」或什么都不做，授权就不会发生。
4. **一次性授权码。** 批准后，浏览器被送回客户端的回调地址，同时带回一个只有 60 秒、只能用一次的授权码。授权码单独拿走没用：客户端发起时就绑定了一把只有它自己知道的「钥匙」（PKCE），换令牌时必须出示。
5. **换令牌。** 客户端用授权码到 `/oauth/token` 换两样东西：访问令牌（`rmo_` 开头，默认 60 分钟有效）和刷新令牌。之后它带着访问令牌调用 `/mcp`；访问令牌到期时它自动用刷新令牌换新的（每次都换一个新的刷新令牌；默认连续 30 天不用或总共满 90 天它就失效，那时需要重新授权）。
6. **随时收回。** 在「已授权的应用」里点「撤销」，令牌立即失效，它正在执行的命令也会被结束；关掉 OAuth 总开关则是全部立刻断开（授权记录保留，重新开启后恢复）。

关于批准页上的黄色提醒：Hub 认得官方 ChatGPT / Claude 的回调地址（`chatgpt.com`、`claude.ai`、`claude.com` 及其子域名），遇到这些来源不提示；遇到其他来源（以及 Claude Code 这类本机回环地址）会显示黄色提醒，请确认你认识这个应用再批准。这是固定规则，没有开关，也不会替你拒绝授权——真正挡在前面的只有总开关、接入窗口（自动注册），以及你自己点的那一下「批准」。

## 环境变量

| 变量 | 说明 |
|---|---|
| `RELAYMESH_PUBLIC_URL` | **推荐在生产设置。** 对外根 URL（如 `https://relaymesh.example.com`），用于 `issuer` 与受保护资源 URL。 |
| `RELAYMESH_OAUTH=off` | **硬开关**：关闭全部 `/.well-known/*` 与 `/oauth/*` 端点（返回 JSON 404）；`/mcp` 行为与未启用 OAuth 时一致（不注入 `WWW-Authenticate`）。 |

### 对外地址优先级

1. 环境变量 `RELAYMESH_PUBLIC_URL`
2. 设置页 **OAuth 策略 → 对外地址**（`oauth.public_url`，保存时校验为 https 源地址，环回主机允许 http）
3. 以上皆无：从请求的 `Host` / `X-Forwarded-Host` / `X-Forwarded-Proto` 推导；此时 OAuth 元数据与授权相关响应带 `Cache-Control: no-store` 与 `Vary: Host, X-Forwarded-Host, X-Forwarded-Proto`，设置页的状态卡会用黄色警告标出「没有设置，按你现在访问页面的地址推导」。

设置页的状态卡显示的就是这里解析出来的结果和它的来源（环境变量 / 设置页 / 推导）；环境变量与设置页同时填了不同的值时，会提示设置页的值被环境变量盖掉了。

### OAuth 授权服务器总开关

设置页 **启用 OAuth 授权服务器** 默认 **关闭**（`RELAYMESH_OAUTH=off` 优先级更高）。开启后才暴露元数据与 `/oauth/*`；自动注册（DCR）默认是**限时窗口**（见下文「自动注册与接入窗口」），同样受总开关管辖。

**生产部署请设置 `RELAYMESH_PUBLIC_URL` 或设置页对外地址**，避免依赖可被客户端影响的请求头。

授权码仅存内存，Hub 重启后未兑换的码失效；同一授权码第二次兑换会作废整条授权（审计 `oauth_code_replay`，不含码本身）。

**关闭总开关 = 立刻断开**：开关关闭（或 `RELAYMESH_OAUTH=off`）时，已签发的 `rmo_` 访问令牌也会被 `/mcp` 拒绝（401）；授权记录与隐藏凭据保留，重新开启后恢复。要永久回收某个应用，请在设置页「撤销」。

修改 OAuth 策略（总开关、对外地址、自动注册、令牌有效期）与批准授权一样需要**终端解锁**（再次验证 Web 密码），并写入审计 `oauth_policy_changed`（只记开关状态，不记地址本身）；拒绝授权不需要解锁。

### 生产首次开启 OAuth 的检查清单

1. 设置 `RELAYMESH_PUBLIC_URL=https://<你的对外域名>`（或在设置页填对外地址），与反向代理一致；不要依赖请求头推导。
2. 设置 `RELAYMESH_TRUSTED_PROXIES` 为反向代理所在网段，使登录、OAuth 与 hook 安装下载的按 IP 限速读到真实客户端 IP。
3. 确认 MCP 本身已启用鉴权（`RELAYMESH_MCP_TOKEN` 或库内令牌）；未配置任何令牌的 Hub 会让 `/mcp` 对任意 Bearer 开放，OAuth 无从谈起。
4. 登录 Web → 设置 → OAuth 授权：先填对外地址，再打开总开关；确认「自动注册」不是「关闭」（ChatGPT / Claude / Claude Code 都靠它连接；只用 CIMD 客户端时可以关闭），保持默认的「限时窗口」，要添加连接器时再开接入窗口。
5. 验证：元数据返回 200；错误的 `redirect_uri` 得到 400 错误页（而不是 302）；无令牌的 `POST /mcp` 返回 `401` 且带 `WWW-Authenticate`；窗口没开着时 `POST /oauth/register` 返回 `403`；开窗口后用一个真实客户端走一遍授权并在设置页看到授权记录，再撤销确认令牌立即失效，最后把接入窗口关上。

## 发现端点

- `GET /.well-known/oauth-protected-resource` — 与下者相同 JSON（资源 URL 为 `{ORIGIN}/mcp`）
- `GET /.well-known/oauth-protected-resource/mcp` — RFC 9728 路径插入式资源元数据（`resource` 字段为 `{ORIGIN}/mcp`）
- `GET /.well-known/oauth-authorization-server` — RFC 8414 授权服务器元数据（`issuer` 为 `RELAYMESH_PUBLIC_URL` 或反代推导的根 URL，无路径）

未提供 OpenID Provider 能力：**不**暴露 `/.well-known/openid-configuration`（该路径返回 JSON `404`，不会被 SPA 接住）。若 `issuer` 带路径前缀的 OIDC 插入式变体不适用本 Hub（单根 issuer、资源固定为 `/mcp`）。

未携带有效令牌的 `POST /mcp` 返回 `401`，并带 `WWW-Authenticate: Bearer resource_metadata="…"`。

## 范围

首发仅开放 ExecMesh 范围：`exec`（终端执行）、`exec:files`（文件）。不开放 `relay`（治理类工具）。

OAuth 访问令牌为 `rmo_` 前缀的不透明串，服务端只存 SHA-256；每次用户批准会创建一条**隐藏 MCP 凭据**，复用终端总闸、主机名单、模式上限、限额、撤销语义（与删除令牌相同，会结束进行中的命令）。

OAuth 令牌**不能**调用 REST / SSE（返回 `403 mcp_token_forbidden`）。

## 用户批准

浏览器访问 `GET /oauth/authorize` 后进入 Web 授权页 `/oauth/consent`：需 Web 登录，授予终端能力前需终端解锁；显示客户端名、重定向主机名与范围；对不是官方 ChatGPT / Claude 来源的客户端、以及仅回环重定向的客户端会显著警告。

批准页上的黄色提醒是**固定规则**，没有设置项，也**只是提醒、从不拒绝授权**：

- 客户端 ID 是 https 地址（CIMD）时，看这个地址的主机名；其余（DCR 注册的）客户端看重定向地址的主机名。主机名是 `chatgpt.com`、`claude.ai`、`claude.com` 或它们的子域名才算官方来源，不提示「不在默认信任列表中」。判断是**精确到域名边界**的：`chatgpt-fake.example.com`、`chatgpt.com.evil.org` 这类长得像的域名都按陌生来源提示。
- 回环重定向（`127.0.0.1` / `localhost`，Claude Code 等本地工具用）始终提示「重定向地址为本机回环地址」。
- 重定向地址或客户端 ID 无法解析时按陌生来源提示。

真正的闸门是总开关、自动注册（DCR）的方式，以及你自己点的那一下「批准」——「自动注册」是「关闭」、或是「限时窗口」而窗口没开着时，`POST /oauth/register` 返回 `403`，只有用 CIMD（客户端 ID 是一个 https 地址）的客户端还能连。

> 2.0.0 及更早的设置页里有「信任 ChatGPT 来源」「信任 Claude 来源」「本机回环」和「自定义信任的客户端域名」四项。它们从来不会拒绝授权，只影响这条提醒，之后的版本已经删除：升级后库里残留的旧值会被忽略，下一次保存策略时一并丢弃，不需要手动处理。

## 自动注册与接入窗口

ChatGPT、Claude、Claude Code 都靠 DCR（`POST /oauth/register`）自己向 Hub 登记。2.0.0 里它只要总开关开着就常开——公网上任何人都能往库里写登记。现在它有三种方式，在 **设置 → OAuth 授权 → 授权服务器设置 → 自动注册** 里选（策略里是 `allow_dcr` 与 `dcr_always` 两个字段）：

| 方式 | 策略 | `POST /oauth/register` |
|---|---|---|
| 关闭 | `allow_dcr=false` | 一律 `403 registration_disabled`；只有 CIMD 客户端还能连 |
| 限时窗口（默认） | `allow_dcr=true`、`dcr_always=false` | 接入窗口开着才受理；窗口外 `403 registration_window_closed`，响应里带一句中英文说明，写明要管理员去哪里开窗口（有的客户端会把它原样显示出来） |
| 常开 | `allow_dcr=true`、`dcr_always=true` | 任何时候都受理（等同 2.0.0 的行为，不建议长期这样） |

**接入窗口**和 ExecMesh「接入主机」里的发现窗口是同一套做法：

- 默认 10 分钟；「续期」在剩余时间上累加（不是重新计时），总剩余最长 60 分钟；「立即关闭」随时可用。开 / 续 / 关都要再次验证 Web 密码，并写入审计 `oauth_window_open`、`oauth_window_close`（带操作者与来源 IP）。接口是 `POST /api/v1/oauth/window`（`{"minutes": 10, "extend": false}`；`extend: true` 表示续期）与 `DELETE /api/v1/oauth/window`。
- 窗口只存在内存里：Hub 重启就关闭。把自动注册改成「关闭」或「常开」、或关掉总开关时，窗口也会被收掉。
- 窗口只管**自动登记**。CIMD 客户端（`client_id` 本身是一个 https 地址）不登记，不受窗口约束；已经登记、已经授权的客户端也不受影响。真正的闸门仍然是总开关，以及你在授权页点的那一下「批准」。
- 窗口开着时设置页每隔几秒自己刷新一次，新登记的客户端会自动出现在清单里，不用手动刷新。

**刚登记、还没授权的客户端**：登记了、但还没走完授权的 DCR 客户端会列在页面上，写着客户端名、回调主机与「官方来源 / 陌生来源 / 本机回环」标记（判断规则与批准页的黄色提醒是同一套）、登记时间与来源 IP。不认识的点「删除登记」：它之后不能再发起授权，它在授权页上等待的请求、还没兑换的授权码也一并作废；删除要再次验证 Web 密码，并写入审计 `oauth_client_delete`。超过 24 小时没人授权的登记，会在下一次有客户端登记时被自动清理。已经授权的应用不在这份清单里，见「已授权的应用」。

> **升级须知**：2.0.0 的自动注册是常开的。升级后，只要「自动注册」是开着的，它的方式就是新的默认「限时窗口」——**下一次添加连接器之前要先开接入窗口**，否则客户端会收到 `403`。想保持旧行为，把「自动注册」改成「常开」。已经授权的客户端不受影响，不需要重新授权。
>
> 另有一处修正：真实 ChatGPT / Claude 通过 https 对外地址登记之后，批准页过去会错把它们当成「陌生来源」显示黄色提醒（登记出来的 client_id 本身以 `https://` 开头，被误当成 CIMD 去比对了 Hub 自己的域名）；现在按它登记的回调地址判断，官方来源不再提示。

## 管理

设置 → **OAuth 授权**：开关接入窗口、查看与删除刚登记的客户端、查看与撤销已授权的应用，以及配置总开关、对外地址、自动注册方式与令牌有效期。

## 客户端注册

- **CIMD**：`client_id` 为 HTTPS 元数据文档 URL（抓取有 SSRF 防护：仅 HTTPS、拒绝内网/回环/链路本地、不跟随重定向、64 KiB / 3 秒上限）。
- **DCR**：`POST /oauth/register`（按自动注册方式受理，见上节；有速率与数量上限）。

刷新令牌每次轮换；重放旧刷新令牌在宽限期外会作废整条授权。

可选的 ChatGPT mTLS 客户端证书校验**未实现**。
